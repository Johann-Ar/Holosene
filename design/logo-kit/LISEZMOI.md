# Logo kit — installation en 3 étapes
1. Dézippe `logo-kit` à la racine de ton projet.
2. Dans le terminal, à la racine du projet : `sh logo-kit/install.sh`
   (copie le kit dans `design/logo-kit`, les SVG dans `public/media`, ajoute les règles à `CLAUDE.md`).
3. Ou plus simple : télécharge juste le zip, ouvre Claude Code dans ton projet et colle `PROMPT-A-COLLER.md` — il installe le kit lui-même.

Mise à jour : si le logo change dans Figma, demande un nouvel export du kit et relance `install.sh`.
